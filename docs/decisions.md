### 2026-07-30 · MapLibre 자동 여행 지도 도입

<span class="status confirmed">결정</span>

**결정**

- Google My Maps는 사용자가 레이어와 핀을 이중 관리해야 하므로 사용하지 않는다.
- MapLibre GL JS와 OpenFreeMap 벡터 스타일로 별도 여행 지도 페이지를 제공한다.
- 공개 관광지는 `docs/assets/map/places.geojson`에서 관리하고 일정 변경 시 Codex가 관련 문서와 함께 갱신한다.
- 실제 숙소 위치, 예약 식당, 가족 개인정보와 실시간 위치는 지도에 넣지 않는다.
- WebGL·외부 지도 로딩에 실패해도 같은 GeoJSON에서 만든 HTML 장소 목록과 Google Maps 링크를 제공한다.

**근거**

- MapLibre는 고해상도 화면에서 선명한 벡터 지도를 제공하고 GeoJSON 기반 날짜·지역 필터를 지원한다.
- OpenFreeMap 공개 인스턴스는 현재 API 키·회원가입·쿠키·요청 제한 없이 사용할 수 있다.
- 코드와 데이터는 Codex가 저장소에서 관리하므로 Google My Maps의 수동 레이어 관리가 필요 없다.
- 지도는 별도 페이지에서만 지연 로딩하므로 다른 일정 페이지의 초기 로딩에 영향을 주지 않는다.

**구현 원칙**

- MapLibre GL JS 5.24.0과 OpenFreeMap Positron 스타일 사용
- 모바일 `cooperativeGestures` 사용, 회전·피치·3D 비활성화
- 관광지 좌표는 표시용이며 실제 입구·주차·운전 경로는 출발 전에 재확인
- 외부 서비스 장애와 WebGL 미지원 환경을 위한 HTML 목록 유지

상세 근거: `research/map-stack-2026-07-30.md`
