# 근교 당일치기

두 번의 렌터카 일정 모두 소형 자동변속 차량과 무료취소 조건을 우선합니다.

## 포지타노 + 아말피 · 라벨로 조건부

**예정일:** 2026년 12월 25일 금요일

<span class="status weather">날씨 조건부</span><span class="status verified">수령 영업 확인</span><span class="status booking">차량·식당 예약 필요</span><span class="status recheck">무인 반납 승인 필요</span>

<p class="route">나폴리 → 포지타노 → 아말피 → 라벨로 선택 → 살레르노 방향 → 나폴리</p>

### 우선순위

1. [포지타노](https://www.google.com/maps/search/?api=1&query=Positano+Italy){ target="_blank" rel="noopener" }: 전망과 짧은 산책
2. [아말피](https://www.google.com/maps/search/?api=1&query=Amalfi+Italy){ target="_blank" rel="noopener" }: 예약 점심과 중심부
3. [라벨로](https://www.google.com/maps/search/?api=1&query=Ravello+Italy){ target="_blank" rel="noopener" }: 날씨·주차·남은 시간이 충분할 때만

### 렌터카 운영 판단

- Avis의 2026년 특별 영업시간상 중앙역점은 08:00~13:00, 공항점은 09:00~20:00에 수령 가능합니다.
- 공항점은 24시간 반납이 공식 표시되어 있습니다.
- 중앙역점은 예약 전에 영업 종료 후 주차장 진입과 열쇠 반납함 사용 승인을 받아야 합니다.
- 중앙역점 무인 반납이 승인되면 08:00 수령이 일조시간 활용에 유리합니다.
- 승인되지 않으면 공항점 수령·반납을 사용합니다.

### 잠정 시간표

1. 08:00 중앙역점 수령 또는 09:00 공항점 수령
2. 10:00~11:15 포지타노 전망·산책
3. 12:15~15:00 아말피 산책·예약 점심
4. 15:00 이후 라벨로 추가 여부 판단
5. 일몰 전 SS163 핵심 구간 종료
6. 살레르노 방향으로 빠져 고속도로로 나폴리 복귀

### 예약 전 확인

- [ ] 자동변속·보험·보증금·무료취소
- [ ] 중앙역점 무인 반납 또는 공항점 24시간 반납
- [ ] 포지타노·아말피 주차장과 ZTL 회피 경로
- [ ] 성탄절 아말피 점심
- [ ] SS163 도로 통제·공사·낙석 공지
- [ ] 일몰시각과 라벨로 생략 기준

강한 비·짙은 안개·강풍·도로 통제가 있으면 취소합니다. 출발 48시간 전 1차, 전날 저녁 최종 결정합니다.

## 치비타 디 바뇨레조 + 오르비에토

**예정일:** 2026년 12월 29일 화요일

<span class="status tentative">잠정</span><span class="status booking">렌터카 예약 필요</span><span class="status recheck">화요일 운영 재확인</span>

<p class="route">로마 → 치비타 디 바뇨레조 → 오르비에토 → 로마</p>

### 잠정 동선

1. 07:30 렌터카 수령 · 08:00 로마 출발
2. 09:45~11:15 [치비타 디 바뇨레조](https://www.google.com/maps/search/?api=1&query=Civita+di+Bagnoregio){ target="_blank" rel="noopener" }
3. 12:15~13:15 [오르비에토 두오모](https://www.google.com/maps/search/?api=1&query=Duomo+di+Orvieto){ target="_blank" rel="noopener" }
4. 13:15 예약 점심 후 구시가지
5. 15:20 성 패트릭 우물 또는 휴식
6. 16:30 로마 복귀 시작

12월 26일 공휴일에서 29일 평일로 이동했으므로 렌터카와 식당 영업은 더 단순해졌습니다. 반면 기존에 검증한 26일 성탄 특별행사 근거는 29일 운영을 직접 증명하지 않으므로, 치비타 매표·두오모 전례·성 패트릭 우물의 화요일 운영을 다시 확인합니다.

## 아말피 악천후 대체안

12월 25일에는 휴관이 많으므로 카세르타를 확정 대안으로 두지 않습니다.

- 나폴리 숙소에서 충분히 휴식
- 영업이 확인된 식당에서 크리스마스 점심
- 날씨가 괜찮아지는 시간에 플레비시토 광장·산타루치아 해안의 짧은 산책
- 27일 나폴리 도보 일정과 일부 교환
