# 여행 지도

확정·잠정 일정에 포함된 **공개 관광지와 확정 숙소**를 5개 권역 지도로 나누어 표시합니다. 장소를 선택하면 방문일과 목표 시간을 확인할 수 있습니다.

휴대폰에서는 권역을 누르면 해당 지도와 장소 목록을 새 화면에서 볼 수 있습니다.

!!! info "지도 관리 원칙"
    지도는 일정 문서와 같은 저장소의 GeoJSON 데이터로 자동 관리합니다. 확정 숙소의 공식 공개 위치는 동선 계획을 위해 표시하지만 예약 식당, 가족 개인정보, 객실·출입정보는 표시하지 않습니다. 지도 로딩이 실패해도 각 지도 안의 장소 목록에서 Google Maps 링크를 이용할 수 있습니다.
