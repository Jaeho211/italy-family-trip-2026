# 여행 지도

!!! info "지도 관리 원칙"
    지도는 일정 문서와 같은 저장소의 GeoJSON 데이터로 자동 관리합니다. 실제 숙소 위치, 예약 식당, 가족 개인정보는 표시하지 않습니다. 지도 로딩이 실패해도 내부 장소 목록의 Google Maps 링크를 이용할 수 있습니다.
