# 로마

로마를 12월 28일부터 1월 2일까지 5박 한 구간으로 묶습니다. 관광일 사이에 근교 운전과 연말 휴식을 번갈아 배치합니다.

<span class="status confirmed">나보나 숙소 예약 완료</span><span class="status recheck">짐 보관 확인</span>

5박 거점은 [iFlat Luxury Navona Apartment](https://www.airbnb.co.kr/rooms/1574501038020607251){ target="_blank" rel="noopener" }입니다. 나보나 광장 바로 뒤의 [Via di Tor Millina 25](https://www.google.com/maps/search/?api=1&query=Via+di+Tor+Millina+25+Roma){ target="_blank" rel="noopener" }에서 판테온·캄포 데 피오리와 연말 구시가지 동선을 도보로 연결합니다. 도착일 체크인 전 짐 보관은 호스트에게 별도로 확인하고, 귀국일은 숙소 보관을 전제로 하지 않고 나보나 인근 외부 짐보관소를 기본안으로 사용합니다.

로마 시내 동선은 사용자 제작 [로마 My Maps 장소 후보](https://github.com/Jaeho211/italy-family-trip-2026/blob/main/research/rome-mymaps-places.md){ target="_blank" rel="noopener" }의 일차별 코스를 그대로 따르기보다, 현재 숙소를 기준으로 지리적으로 이어지는 구간만 선별해 재구성합니다.

## 12월 28일 · 판테온과 구시가지

<span class="status tentative">잠정</span><span class="status verified">일반 운영 확인</span><span class="status review">사전구매 권장</span>

나폴리 출발 → 로마 도착·짐 보관/체크인 → 점심 → [Pantheon](https://www.google.com/maps/search/?api=1&query=Pantheon+Rome){ target="_blank" rel="noopener" } → Piazza Navona → Campo de' Fiori → 숙소

- 나폴리에서 이동하는 날이므로 판테온을 너무 이르게 고정하지 않고 **16:00 전후 내부 관람**을 목표로 합니다.
- 일반 운영은 09:00~19:00, 개인 마지막 입장은 18:30입니다.
- 12월 25일과 1월 1일은 휴관이므로 28일은 현재 규정상 운영일입니다.
- 어린이 무료 입장권도 함께 발급하고 연령 증빙을 준비합니다.
- 숙소 공개 체크인은 15:00 이후입니다. 체크인 전 도착하면 호스트 짐 보관 가능 여부를 확인하고, 불가하면 나보나 인근 외부 짐보관을 사용합니다.
- 판테온 관람 후 나보나 광장과 캄포 데 피오리를 연결하는 짧은 도보 루프로 마무리해 첫날 체력을 아낍니다.

[판테온 공식 안내](https://direzionemuseiroma.cultura.gov.it/en/pantheon/){ target="_blank" rel="noopener" } · [상세 조사](https://github.com/Jaeho211/italy-family-trip-2026/blob/main/research/pantheon-2026-12-28.md){ target="_blank" rel="noopener" }

## 12월 29일 · 바티칸과 백조의 호수

<span class="status tentative">일정 합의</span><span class="status verified">박물관·공연 확인</span><span class="status waiting">티켓 판매 대기</span><span class="status booking">발레 2석 예매 필요</span><span class="status recheck">대성당 시간 재확인</span>

[바티칸 박물관](https://www.google.com/maps/search/?api=1&query=Vatican+Museums){ target="_blank" rel="noopener" } → 시스티나 성당 → [성베드로 광장](https://www.google.com/maps/search/?api=1&query=St+Peters+Square+Vatican){ target="_blank" rel="noopener" } → Via della Conciliazione → Castel Sant'Angelo 외관 → Ponte Sant'Angelo → 숙소

- 07:30 도착, **08:00 바티칸 박물관 입장권**을 우선하고 매진 시 08:30 → 09:00 순으로 확인합니다.
- 오전에 바티칸 박물관과 시스티나 성당을 보고 정오 전후 성베드로 대성당과 광장으로 이동합니다.
- 박물관 입장권에는 시스티나 성당이 포함되지만 성베드로 대성당은 별도 보안검색이 필요합니다. 박물관에서 대성당으로 바로 빠지는 전용 동선을 일정 전제로 두지 않습니다.
- 늦은 점심 후 **Via della Conciliazione → 산탄젤로성 외관 → 성천사의 다리**를 따라 나보나 숙소 방향으로 걷습니다. 산탄젤로성 내부 관람은 넣지 않습니다.
- 15:30 전후 숙소 복귀를 목표로 충분히 쉬고, 아내와 딸은 이른 저녁 후 Teatro Costanzi로 이동합니다.
- 20:00 《백조의 호수》는 Fumi Kaneko와 Vadim Muntagirov 출연 회차이며 인접 좌석 2석을 확보합니다.
- 나머지 가족은 공연 시간에 자유 일정과 휴식을 갖습니다.

!!! warning "공식 포털만 사용"
    [Vatican Museums 공식 티켓 포털](https://tickets.museivaticani.va/){ target="_blank" rel="noopener" }에서만 구매합니다.

## 12월 30일 · 치비타와 오르비에토

아내의 핵심 희망지인 치비타 디 바뇨레조를 오르비에토와 묶어 하루 렌터카로 다녀옵니다. 전날 발레는 아내와 딸만 관람하므로 가족 전체의 운전일 부담을 늘리지 않습니다. 성 패트릭 우물은 전날 귀가 시간과 당일 체력에 따라 선택합니다. 세부 동선은 [근교 당일치기](day-trips.md)에서 관리합니다.

## 12월 31일 · 트레비·스페인·핀초와 새해 전야

<span class="status tentative">잠정</span><span class="status booking">저녁 예약 필요</span><span class="status recheck">공식 행사 발표 대기</span>

숙소 → Trevi Fountain → Spanish Steps → Trinità dei Monti → 점심 → Pincio → Piazza del Popolo → 숙소 휴식 → 새해 전야

- **10:30 전후 숙소 출발**로 너무 늦게 시작하지 않습니다.
- 트레비 분수 → 스페인 광장·계단 → Trinità dei Monti를 한 방향으로 연결합니다.
- 점심 후 Pincio 전망대와 Piazza del Popolo까지 이어서 보고, 보르게세 공원 안쪽으로는 깊게 들어가지 않습니다.
- 15:30~16:00 전후 숙소 복귀를 목표로 오후를 비워 자정 행사 체력을 확보합니다.
- 새해 전야 저녁은 사전예약하고, 로마시 공식 행사·교통 통제가 발표되면 자정 관람 위치와 귀가 동선을 확정합니다.

## 1월 1일 · 신년행사와 트라스테베레 백업 코스

<span class="status tentative">잠정</span><span class="status recheck">공식 프로그램 발표 대기</span>

- 전날 귀가 시간에 맞춰 늦게 시작하고 **Rome Parade 또는 Roma Capodarte의 가족형 공식 프로그램을 우선**합니다.
- 공식 행사가 가족 일정과 맞지 않으면 보르게세 공원 대신 오후에 **택시로 Gianicolo 전망대까지 올라간 뒤 내리막 중심으로 걷는 백업 코스**를 사용합니다.
- 백업 코스는 Gianicolo → Fontana dell'Acqua Paola → Santa Maria in Trastevere → Piazza Trilussa → Ponte Sisto → 나보나 숙소 순서입니다.
- 자니콜로는 숙소에서 걸어 올라가지 않고 택시로 정상부에 접근해 아이들의 오르막 부담을 줄입니다.
- 트라스테베레에서 이른 저녁을 먹고 Ponte Sisto를 건너 숙소까지 도보 복귀하는 흐름으로 마무리합니다.
- 신정 휴관을 고려해 예약이 필요한 핵심 유료 관광지는 넣지 않습니다.

## 1월 2일 · 고대 로마와 귀국

<span class="status tentative">잠정</span><span class="status verified">겨울 운영 확인</span><span class="status waiting">30일 전 판매 대기</span><span class="status recheck">짐보관·택시요금 재확인</span>

10:00 체크아웃 → 나보나 인근 외부 짐보관 → [Colosseum](https://www.google.com/maps/search/?api=1&query=Colosseum+Rome){ target="_blank" rel="noopener" } → [Roman Forum](https://www.google.com/maps/search/?api=1&query=Roman+Forum+Rome){ target="_blank" rel="noopener" } → Palatine Hill → 늦은 점심 → 나보나 짐 수령 → FCO 직행

- 아침은 숙소에서 여유 있게 보내고 공개 체크아웃 시각인 10:00에 맞춰 퇴실합니다.
- 체크아웃 후 숙소 짐 보관은 전제로 하지 않고 Piazza Navona 인근 외부 짐보관소를 기본안으로 사용합니다.
- 기본 24h 통합권의 **11:00 콜로세움 입장**을 목표로 가족 4명의 같은 시간대를 확보합니다.
- 11:00~12:15 콜로세움, 12:20~14:30 포로·팔라티노를 기준으로 하고 이후 늦은 점심을 먹습니다.
- 16:30 전후 나보나로 돌아와 짐을 수령하고 **17:00~17:30경 Roma Capitale 공식 택시로 FCO에 직행**합니다. Termini·Leonardo Express는 귀국일 기본 동선에서 제외합니다.
- 현재 Roma Capitale 공식 정액은 아우렐리아누스 성벽 내부 ↔ Fiumicino Airport 직행이 **€55**입니다. 4인 가족 기준이며, 여행 직전에 최신 요금과 적용 조건을 다시 확인합니다.
- 판매는 방문 30일 전에 시작하므로 2026년 12월 3일경 공식 창을 확인합니다.
- 일정이 밀리면 포로·팔라티노 범위를 줄이고 22:00 항공편을 위한 공항 이동 여유를 우선합니다.
