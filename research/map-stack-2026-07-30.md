# 여행 지도 기술 선택과 운영 근거

- 확인일: 2026-07-30
- 대상: GitHub Pages로 배포하는 MkDocs 가족여행 사이트
- 결론: MapLibre GL JS + OpenFreeMap + 저장소 관리 GeoJSON

## 요구사항

- Google My Maps에서 사용자가 레이어와 핀을 수동으로 관리하지 않을 것
- API 키와 결제계정이 필요하지 않을 것
- 모바일 고해상도 화면에서 선명한 지도를 제공할 것
- 권역별 지도, 관광지 팝업, Google Maps 이동 링크를 제공할 것
- 일정이 바뀌면 Codex가 문서와 지도 데이터를 함께 갱신할 것
- 지도 장애나 WebGL 미지원 환경에서도 장소 목록을 사용할 수 있을 것
- 공개 저장소와 지도에 실제 숙소 위치나 예약·개인정보를 기록하지 않을 것

## 후보 비교

### Leaflet

Leaflet은 모바일 친화적인 오픈소스 지도 라이브러리이며 마커, 팝업, GeoJSON, 래스터 타일을 간단한 API로 제공한다. 이번 정도의 관광지 수에는 충분하지만, OpenStreetMap 표준 PNG 타일을 사용할 경우 확대 중 선명도와 벡터 스타일링은 MapLibre보다 제한적이다.

### MapLibre GL JS

MapLibre GL JS는 WebGL로 벡터 타일을 렌더링한다. GeoJSON 데이터 소스와 표현 레이어를 분리해 권역별 장소를 표시하고 데이터 기반 색상을 적용할 수 있다. WebGL과 스타일·벡터 타일 제공처가 필요해 Leaflet보다 설정이 복잡하지만, 코드를 저장소에서 고정하고 Codex가 유지하면 사용자가 부담할 수동 작업은 없다.

### OpenLayers

OpenLayers는 GIS 기능이 가장 풍부하지만 이번 사이트에 필요하지 않은 투영·분석 기능과 빌드 복잡도가 커서 제외한다.

### Google Maps API와 My Maps

Google Maps Embed/JavaScript API는 API 키와 Google Cloud 설정이 필요하고, My Maps는 사용자가 공개 지도와 레이어·핀을 별도로 관리해야 하므로 자동화 목표와 맞지 않는다.

### PMTiles 자체 호스팅

정적 단일 타일 아카이브로 외부 서비스 의존을 줄일 수 있지만 이탈리아 배경 지도 생성·저장·갱신 부담이 커서 제외한다.

## 선택한 구성

- MapLibre GL JS 5.24.0 고정 버전
- OpenFreeMap Positron 공개 스타일
- `docs/assets/map/places.geojson`을 관광지 단일 데이터 원본으로 사용
- 지도 페이지에서 지도 전용 `region` 값으로 GeoJSON 피처 필터링: 나폴리, 폼페이, 아말피, 로마, 치비타·오르비에토
- 마커 팝업과 HTML 장소 목록을 같은 GeoJSON에서 생성
- `cooperativeGestures`로 모바일 페이지 스크롤과 지도 조작 충돌 완화
- 회전·피치·3D 기능은 비활성화
- WebGL 미지원, 스크립트·스타일·타일 장애 시 HTML 장소 목록 유지

## 2026-07-31 운영 변경: 5개 권역 지도

### 변경 내용

- 단일 지도와 날짜·지역 체크박스 대신 5개의 권역 지도를 사용한다.
- 나폴리, 폼페이, 아말피, 로마, 치비타·오르비에토를 각각 별도 지도에 표시한다.
- 각 GeoJSON 피처의 `region` 값으로 지도 표시 범위를 결정하고, 기존 `group` 값은 마커 색상용으로만 사용한다.

### 판단 근거

- 이는 새 외부 사실이 아닌, 기존 GeoJSON 좌표 범위와 일정의 출발지를 바탕으로 한 화면 구성 판단이다.
- 관광지 마커 미표시 보고는 내부 구현 문제로 분류한다. 권역과 색상 분류를 분리하면 각 지도에 포함할 피처 수를 직접 검증할 수 있다.
- 5개 지도는 각 권역의 마커를 자동으로 맞춰 보여 주므로, 넓은 이탈리아 전역을 한 지도에 표시할 때보다 모바일에서 확대·축소 부담이 작다.

## 외부 의존성과 주의사항

- OpenFreeMap 공개 인스턴스는 가입, API 키, 쿠키, 요청 제한 없이 사용할 수 있다고 안내하지만 SLA를 제공하지 않는다.
- MapLibre는 WebGL이 필요하므로 초기화 전에 지원 여부를 확인한다.
- MapLibre의 기본 CSP는 Web Worker와 `blob:` 허용이 필요하다. 현재 GitHub Pages 사이트에는 별도 제한적 CSP가 없지만 향후 추가한다면 공식 CSP 안내를 반영한다.
- 공개 지도에는 관광지와 공개 교통거점만 기록하고 정확한 숙소·예약 식당·개인정보는 기록하지 않는다.
- GeoJSON 좌표는 실행용 표시 좌표이며 실제 입구·주차·운전 경로는 방문 전에 공식 안내와 Google Maps에서 다시 확인한다.
