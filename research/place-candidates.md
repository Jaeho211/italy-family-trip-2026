# 장소 후보 메모

외부 지도, 여행 글과 가족 제안에서 발견한 장소를 일정 확정 전에 모아 두는 대기 문서입니다. 이 문서에 기록됐다는 이유만으로 일정이나 공개 여행 지도에 포함된 것은 아닙니다.

## 반영 절차

1. 이 문서에 `미검증 후보`로 기록
2. 우리 동선·가족 관심도와 맞는지 검토
3. 운영시간·휴관일·예약 필요 여부를 공식 출처로 확인
4. 실제 일정에 채택하면 관련 `research/`와 `docs/`에 근거와 실행 결론 반영
5. 공개 관광지라면 같은 변경에서 `docs/assets/map/places.geojson` 갱신

## 기록 규칙

- 출처 URL과 확인일을 남깁니다.
- `공식 사실`, `여행자 추천`, `가족 관심`, `미확인`을 구분합니다.
- 가격·운영시간은 이 문서에서 확정하지 않고 공식 출처로 다시 확인합니다.
- 확정 숙소의 공식 공개 위치는 동선 계획용 지도에 기록할 수 있지만 예약 식당, 가족 개인정보, 객실·출입정보와 실시간 위치는 기록하지 않습니다.
- 후보에서 제외해도 판단 이력을 위해 항목은 남기고 제외 이유를 적습니다.

## 상태

- `미검증 후보`: 외부 자료에서 가져왔지만 아직 사실과 동선을 확인하지 않음
- `검토 중`: 일정 적합성과 공식 정보를 확인 중
- `채택`: 일정과 관련 문서에 반영 완료
- `보류`: 이번 일정에는 넣지 않지만 예비 후보로 유지
- `제외`: 방문하지 않기로 결정하고 이유를 기록

## 장소별 기록 형식

### 장소명

- **권역:** 로마 / 나폴리 / 폼페이 / 아말피 / 치비타·오르비에토
- **분류:** 관광지 / 박물관 / 교회 / 공원 / 쇼핑 / 식사 참고 / 기타
- **상태:** 미검증 후보
- **발견 출처:** 링크
- **관심 이유:** 가족이 검토할 이유
- **공식 출처:** 검증 전에는 `미확인`
- **확인일:** YYYY-MM-DD
- **재확인 시점:** 일정 채택 전
- **일정 반영:** 미반영
- **지도 반영:** 미반영
