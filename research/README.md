# 여행 조사 자료

이 디렉터리는 GitHub Pages에 모두 표시하기에는 지나치게 상세한 여행 조사 결과와 출처를 보관한다. `docs/`가 가족이 여행 중 실제로 읽는 실행 계획이라면, `research/`는 그 결론에 도달한 근거와 불확실성을 보존하는 기록이다.

`research/`는 MkDocs의 `docs_dir` 밖에 있어 Pages 메뉴나 빌드 결과에는 포함되지 않는다. 그러나 이 저장소 자체가 공개 저장소이므로 GitHub에서는 누구나 읽을 수 있다.

## 문서 원칙

- 공식 사실, 과거 사례, 추론, 미확인을 명확히 구분한다.
- 운영시간과 가격처럼 변경 가능한 정보에는 확인일과 재확인 시점을 기록한다.
- 가능하면 공식 기관이 게시한 원문을 우선 사용한다.
- 공식 출처가 없으면 그 사실을 명시한다.
- 추정이나 일반적인 관행을 공식 규칙처럼 쓰지 않는다.
- 일정의 결론이 바뀌면 관련 조사 문서와 `docs/decisions.md`를 함께 갱신한다.
- 대화 원문을 그대로 복사하지 않고 검증 가능한 조사 결과로 정리한다.
- 예약번호, 실명, 생년월일, 여권정보, 연락처, 결제정보, 실제 숙소 주소와 출입정보는 기록하지 않는다.
